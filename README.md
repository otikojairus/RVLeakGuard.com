# RV Leak Guard

Programmatic SEO site for **Canada RV / camper water damage** services, generated from `pSEO - Canada Water Damage for RV.xlsx`.

## Stack

- Next.js 15 (App Router), static generation for **456** service/location pages
- Content data: `data/pages.json` (regenerate with `python3 scripts/generate-pages.py`)

## Commands

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm start
```

## Brand / contact

Edit `lib/site.ts` for phone, hours, and domain (`rvleakguard.com`).
